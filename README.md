# 인천 아일랜드 투어 MVP

정적 HTML/CSS/JS로 만든 반응형 MVP입니다.

## 포함 페이지
- `index.html` 메인
- `about.html` 회사소개
- `tours.html` 투어상품 + 간단 필터
- `reviews.html` 후기
- `faq.html` FAQ 아코디언
- `contact.html` 문의/예약 유도 폼

## 핵심 구현
- 모바일/태블릿/데스크톱 반응형
- 상단 CTA 및 모바일 하단 고정 CTA
- 상품 → 문의 페이지로 투어명/문의유형 전달
- 투어상품 카테고리 필터
- FAQ 아코디언
- 문의 폼 유효성 검사 및 완료 상태 시뮬레이션
- 운영경력/후기/사진/FAQ 신뢰 요소

## 중요
- 운영경력 수치, 상품명, 후기, 이미지 일부는 MVP 구조 검증용 예시입니다.
- 실제 공개 전에 검증된 운영경력, 실제 투어 사진, 실제 고객 동의 후기, 일정·가격, 취소/결항 정책으로 교체해야 합니다.
- 문의 폼은 현재 실제 전송되지 않습니다. 운영 버전에서는 서버/API, 이메일, CRM 또는 예약 솔루션 연결이 필요합니다.
- 원격 이미지는 Unsplash URL을 사용하므로 인터넷 연결이 필요합니다. 공개 버전에서는 실제 촬영 이미지를 자체 호스팅하는 것을 권장합니다.

## 실행
폴더에서 정적 서버를 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.


## 관리자 대시보드
- 경로: `/admin/`
- 정적 MVP이며 브라우저 localStorage 기반입니다.
- 실제 운영 전 인증/DB/API 연결이 필요합니다.
